# SECURITY

Trowl is an open-source project without warranty or guaranteed support. Maintainers will do the best they can to address issues on a priority basis.

## Reporting a vulnerability

Please report privately using GitHub's Private vulnerability reporting feature under the repository's Security tab.

Avoid publicly disclosing vulnerabilities before they have been assessed.

### ⚠️  Scope

This policy is limited to vulnerabilities in Trowl (e.g., parser code, scan logic, etc.)

If you discover a bug in a dependency package used by Trowl instead, please open a ticket in GitHub Discussions so that the maintainers and community can address it appropriately.
