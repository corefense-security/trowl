## What Trowl downloads

| Data | Source | Refreshed |
| --- | --- | --- |
| NVD and kernel CNA records | NVD JSON feeds mirror on GitHub | Every 24 hours |
| CISA KEV | GitHub mirror, then cisa.gov | Daily |
| EPSS | empiricalsecurity.com | Daily |
| Advisory links | NVD, OSV, cve.org and the kernel CNA | Every 7 days |
| Summary model | Hugging Face, at a pinned revision with a checked SHA-256 | Once |

If a refresh fails, Trowl uses the copy it already has.

## Cache location

Everything goes to `$XDG_CACHE_HOME/trowl`, which is usually `~/.cache/trowl`. In Docker, mount it at `/cache/trowl`:

```sh
-v ~/.cache/trowl:/cache/trowl
```

Leave out the mount and every container run downloads the feeds and the 2.7 GB model again.

## Offline scans

```sh
trowl scan image.ext4 --no-network -o report
```

`--no-network` matches CVEs against the NVD data already in the cache and skips KEV, EPSS and link checks. Run one scan with network access first to fill the cache.

## The summary model

The Overview summary comes from a small model that runs locally through `llama-server`. Only numbers computed by the scan go into it. Nothing leaves your machine. If `llama-server` is not installed, the scan skips the summary.

| Model | Notes |
| --- | --- |
| `qwen3.5-4b` | Default |
| `qwen3.5-9b` | Larger and slower |
| `qwen3-4b` | Older |

Weights come from Hugging Face under the Apache 2.0 licence.
