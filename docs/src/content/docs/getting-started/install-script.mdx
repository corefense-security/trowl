The script builds Trowl from source and installs it to `/usr/local/bin`, along with necessary tools and dependencies.

## Requirements

- Debian or Ubuntu on `x86-64` or `arm64`
- `sudo` for system packages and installation.

## Installation

:::note
Use a preview tag until the first stable release.

```sh
REF=v0.1.0-preview.4
```
:::

```sh
curl -fsSL https://raw.githubusercontent.com/corefense-security/trowl/main/install.sh | bash -s -- --ref "$REF"
```

Go and Node are downloaded to a temporary folder and removed after the build. Verify the installation:

```sh
trowl --version
```

### Installer options

| Option | Effect |
| --- | --- |
| `--with-llm` | Also install `llama-server` for the Overview summary |
| `--prefix DIR` | Install to `DIR/bin` instead of `/usr/local/bin` |
| `--ref REF` | Build a branch or tag instead of `main` |
| `--source DIR` | Build from a local checkout instead of cloning |

### Overview summary

Add `--with-llm` to build `llama-server` from llama.cpp for the Overview summary. This adds a few minutes to installation.

```sh
curl -fsSL https://raw.githubusercontent.com/corefense-security/trowl/main/install.sh | bash -s -- --ref "$REF" --with-llm
```

Without `llama-server`, scans run without the summary.

## Run a scan

Only the image is required. [Your first scan](../first-scan/) covers optional inputs and their Yocto build paths.

```sh
trowl scan core-image-minimal-qemux86-64.rootfs.ext4.zst \
  --sbom core-image-minimal-qemux86-64.rootfs.spdx.json \
  --kernel-config kernel.config \
  -o report
```

The first scan downloads CVE feeds to `~/.cache/trowl` for reuse. With the summary enabled, it also downloads the model (about 2.7 GB). See [Network and cache](../../reference/architecture/#network-and-cache).

## Open the report

Open `report/index.html` directly or serve the report locally:

```sh
trowl view report  # http://127.0.0.1:8765
```

Press Ctrl+C to stop the viewer.

See [Report output](../../reference/report/) for JSON contents and static hosting.
