Trowl's Docker image includes filesystem extraction tools and `llama-server` for the LLM summary. It runs with Docker on Linux, macOS or Windows.

## Installation

:::note
Use a preview tag until the first stable release.

```sh
REF=v0.1.0-preview.4
```
:::

```sh
docker pull ghcr.io/corefense-security/trowl:$REF
```

## Run a scan

Only the image is required. [Your first scan](../first-scan/) covers optional inputs and their Yocto build paths.

1. Put the inputs in one folder.

   ```
   ~/trowl-in/
   ├── core-image-minimal-qemux86-64.rootfs.ext4.zst
   ├── core-image-minimal-qemux86-64.rootfs.spdx.json
   └── kernel.config
   ```

2. Create the output and cache folders under your user account.

   ```sh
   mkdir -p ~/trowl-out ~/.cache/trowl
   ```

3. Run the scan.

   ```sh
   docker run --rm -t \
     --user "$(id -u):$(id -g)" \
     -v ~/trowl-in:/in:ro \
     -v ~/trowl-out:/out \
     -v ~/.cache/trowl:/cache/trowl \
     ghcr.io/corefense-security/trowl:$REF \
     scan /in/core-image-minimal-qemux86-64.rootfs.ext4.zst \
       --sbom /in/core-image-minimal-qemux86-64.rootfs.spdx.json \
       --kernel-config /in/kernel.config \
       -o /out/report
   ```

Input paths refer to files inside the container and must be mounted. For kernel VEX assessment, also mount the source with `-v ~/src/linux-6.18.52:/tree:ro` and pass `--kernel-tree /tree`.

### Downloads and cache

The mounted cache stores CVE feeds and the summary model in `~/.cache/trowl` on the host. The first scan downloads the model (about 2.7 GB). Later scans reuse cached files. See [Network and cache](../../reference/architecture/#network-and-cache).

## Open the report

Open `~/trowl-out/report/index.html` directly or serve the report locally:

```sh
docker run --rm -it -p 8765:8765 \
  -v ~/trowl-out:/out:ro \
  ghcr.io/corefense-security/trowl:$REF \
  view /out/report
```

Open `http://localhost:8765` and press Ctrl+C to stop the viewer.

See [Report output](../../reference/report/) for JSON contents and static hosting.
