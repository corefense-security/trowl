## Installation

Trowl's Docker image includes filesystem extraction tools and `llama-server` for the LLM summary. It runs with Docker on Linux, macOS or Windows.

```sh
docker pull ghcr.io/corefense-security/trowl:$TAG
```

:::note
Replace `$TAG` with a release tag. Use a preview tag until the first stable release.
:::

### Verify the image

Release images are signed with [Cosign](https://docs.sigstore.dev/cosign/system_config/installation/) using GitHub Actions.

With Cosign 3+ and Docker Buildx installed, replace `vX.Y.Z` with the release tag, including any preview suffix. Keep both certificate flags as shown, as they identify Trowl's release workflow and GitHub Actions as its identity provider.

```sh
TAG='vX.Y.Z'
IMAGE="ghcr.io/corefense-security/trowl"
DIGEST="$(docker buildx imagetools inspect "$IMAGE:$TAG" --format '{{.Manifest.Digest}}')"

cosign verify "$IMAGE@$DIGEST" \
  --certificate-identity "https://github.com/corefense-security/trowl/.github/workflows/build-release-trowl.yml@refs/tags/$TAG" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

## Scan a Yocto image

Put the Yocto image, its SBOM and `kernel.config` in `~/trowl-in/`, then run:

```sh
# Create host directories owned by your user.
mkdir -p ~/trowl-out ~/.cache/trowl

docker run --rm -t \
  --user "$(id -u):$(id -g)" \
  -v ~/trowl-in:/in:ro \
  -v ~/trowl-out:/out \
  -v ~/.cache/trowl:/cache/trowl \
  ghcr.io/corefense-security/trowl:$TAG \
  scan /in/core-image-minimal-qemux86-64.rootfs.ext4.zst \
    --sbom /in/core-image-minimal-qemux86-64.rootfs.spdx.json \
    --kernel-config /in/kernel.config \
    -o /out/report
```
> See [Yocto integration](../../integrations/yocto/) to scan images during a build.

## Scan a Buildroot image

Put `output/images/rootfs.ext4` from your Buildroot build in `~/trowl-in/`, then run:

```sh
mkdir -p ~/trowl-out ~/.cache/trowl

docker run --rm -t \
  --user "$(id -u):$(id -g)" \
  -v ~/trowl-in:/in:ro \
  -v ~/trowl-out:/out \
  -v ~/.cache/trowl:/cache/trowl \
  ghcr.io/corefense-security/trowl:$TAG \
  scan /in/rootfs.ext4 -o /out/report
```

### Kernel VEX

Trowl can perform VEX on [kernel CVEs](../../features/cves-vex/#kernel-cves) with or without an SBOM. To enable, mount the source tree with `-v ~/src/linux:/tree:ro` and pass `--kernel-tree /tree`.

### Cache

Mount the host cache at `/cache/trowl` to reuse downloads between containers:

```sh
-v ~/.cache/trowl:/cache/trowl
```

See [Data fetching and caching](../../reference/architecture/#network-and-cache).

### Local AI summary

Docker mode generates LLM scan summary by default. Pass `--no-llm` after `scan` to skip AI summary and model weight downloads.

For details, refer to [Local AI summary](../../reference/architecture/#local-summary).

## Open the report

Open `~/trowl-out/report/index.html` directly or serve the report locally:

```sh
docker run --rm -it -p 8765:8765 \
  -v ~/trowl-out:/out:ro \
  ghcr.io/corefense-security/trowl:$TAG \
  view /out/report
```

Open `http://localhost:8765` and press Ctrl+C to stop the viewer.

See [Report output](../../reference/report/) for more details.
